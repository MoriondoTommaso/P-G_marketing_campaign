## Team 4 handoff and open evidence

- **Available now.** Start with the proposed shelf guide. The case directly supports easy navigation, and Team 4 can prototype a timed variant-finding task using neutral product descriptors and the same assortment in both layouts. Keep the comparison card and restock prompt as alternatives if retailers can support the display and measurement. If class materials become available, map documented personas to relevant needs and approved SKUs. Until then, use the matrix's shopper situations as hypotheses.
- **After T07.** Use profile directions, denominators and sample sizes to choose where each idea is feasible to test. Catchment comparisons can inform locations. They cannot validate a shopper need, willingness to trade up or message response. Validate those hypotheses with observed shelf tasks, pre-exposure intercepts or transaction data as appropriate.
- **After T11.** Check selected-store coverage and retailer permissions before attaching tactics to the funded list. If rollout evidence is weak, use a bounded test. Where feasible, randomize comparable stores to proposed and usual displays, match observation windows, and record execution, stockouts, prices and promotions. Analyze outcomes by assigned store; use execution data to interpret the result. Without randomization, state the limits of a comparison. Track brand share only if the retailer can supply a consistent category denominator, such as all toothpaste units in the same stores and periods. Store success labels cannot establish brand-share lift.
