2027 store activation: what is the opportunity worth?

Recommendation: approve the design of a capped, equal-budget pilot. The tree identifies 287 stores with positive expected value. Activating all of them would cost €430,500 and yield an estimated €234,153.75 in net campaign value. This is a planning scenario; the historical sample does not establish the return in never-activated stores.

Campaign economics

All amounts are incremental to ordinary store sales. A successful activation generates €2,500 in incremental sales; every activation costs €1,500. Net campaign value is incremental sales less activation spend, before product costs or other overhead.

What was actually observed?

In 2026, 108 of 170 activations succeeded. Applying the tree’s held-out decisions retrospectively would have funded 108 stores: 100 observed successes and 8 failures, for €88,000 retrospective net (€250,000 sales less €162,000 spend). The campaign actually earned €15,000 net. The €73,000 difference is a historical backtest.

For 2027, the 108 selected repeat stores contribute €88,301.90 expected net; the 179 selected new stores contribute €145,851.85 expected net. Both are forecasts. Together they make up the €234,153.75 scenario.

Oral-B Italy · Decision and reconciliation

How much should we commit?

Agree the pilot budget before selecting stores. Each pair of activations, one in each test arm, costs €3,000. Choose a cap that can fund the minimum sample needed to make an expansion decision.

Downside if scores are too optimistic

The full commitment needs 173 successful activations out of 287 to cover its cost: 172 successes would lose €500; 173 would earn €2,000. The model implies about 266 successes. The 170 historic activations were selected, and neither planned geographic holdout had sufficient support to validate transfer.

Decision and next steps

  1. Team 4 — reconcile the handoff. Verify the workflow fingerprint below, run it into an empty output folder, and reconcile the 287 exact IDs and the three differences on page 1. Use the class exports for these figures; the older 278-store RC3 summary describes a different policy.
  2. Campaign owner — design the test. Set the spend cap, duration, outcome window, minimum worthwhile return and sample size before seeing results. Freeze the tree and the strict funding rule. Within region and new/repeat groups, randomly assign comparable store pools to tree targeting or current practice and give each arm the same activation budget.
  3. Expansion decision. Track actual activations, successes, spend, and realized net per euro by arm and region. Expand only if the pilot clears the agreed financial criterion with adequate evidence; otherwise hold spending and review where forecasts failed.

Calculation and source record

Score all 480 stores once: 170 historical stores use held-out scores; 310 new stores use the tree refit on the historical sample. Fund only if unrounded p > 0.60. For any selected set: sales = €2,500 × sum(p); spend = €1,500 × count. For equal spend rank positive-value stores by probability descending, then text store ID ascending. Compare the top 170 with all 170 historical IDs, using the same probability wherever a store recurs. Differences use unrounded values; round only for display.
